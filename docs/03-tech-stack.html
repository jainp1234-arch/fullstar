1Rules for Claude Code

  1. Use exactly the versions in this document. No ^, ~, latest, LATEST or version ranges in package.json, pom.xml, requirements.txt, Dockerfiles or GitHub Actions.
  2. Commit package-lock.json and use npm ci in CI. Python requirements.txt files list every package with an exact == pin from this document.
  3. Spring-managed libraries take their version from the Spring Boot 4.1.1 BOM. Do not override a Boot-managed version unless this document says so.
  4. Pin every Docker image to an exact tag (never latest or a major-only tag). Before first use, confirm the tag exists with docker pull; if it does not, stop and report rather than picking another version.
  5. All images must build for linux/amd64 and linux/arm64 (the demo server is ARM).
  6. Do not add a dependency that is not in this document. If one is needed, stop and propose it with its version, GitHub stars, age and licence.
  7. Never commit secrets. Read them from environment variables; provide a .env.example with names only.

10Engineering conventions

AreaRule
REST APIVersioned under /api/v1. Every response uses { "status", "data", "error" }. Correct HTTP status codes. Validation with Bean Validation on every request body.
ErrorsCustom exceptions mapped in one @RestControllerAdvice. No stack traces in responses.
SecurityKeycloak JWTs checked by Spring Security resource server. Deny by default. Every query checks the family ID (stops one family seeing another's data). OWASP Top 10 checklist in code review.
ResilienceResilience4j on every outside call (Claude, R2, SQS, Gotenberg): retry with exponential backoff, circuit breaker, timeout.
QueuesEach job carries an idempotency key; workers skip jobs already done. Max 3 receives, then the dead-letter queue. DLQ depth raises an alert.
LoggingStructured JSON logs through SLF4J. Never log names, phone numbers, recordings or book text.
FrontendStandalone components, reactive forms, strong typing (no any). UI components separate from services holding business logic.
UploadsPDF up to 50 MB and 300 pages; JPG/PNG up to 10 MB, 50 per upload. Check file type by content, not by name. ClamAV scan before any processing.
