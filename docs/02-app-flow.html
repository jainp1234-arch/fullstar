1Decisions for this version

Account

  • Sign-up is required. The first screen offers Sign in or Sign up.
  • Email + one-time code (sent by email). One parent login per family.
  • App language: English only (the Hindi subject stays).
  • No payments, trial or subscription screens.

Children

  • Up to 2 child profiles. No child PIN: the child taps their picture.
  • Subjects come from the class: English, Hindi, Maths, EVS. Computer is left out for now.
  • One book per subject, uploaded by the parent. No book list to pick from.
  • No daily plan, no streaks, no bonus activities. Stars are for fun only.

When there is no book

  • English, Hindi, Maths: grade-level grammar and practice.
  • EVS: grade-level general concepts.
  • The child always has something to do.

Messages and limits

  • All messages stay inside the app (no SMS, WhatsApp or email).
  • Daily time limit shows as an indicator that turns from green to red. The app never locks the child out.
  • Every kid-mode screen has a 🔊 button that reads the instructions aloud.

7Content Studio screens (teachers)

A separate site for our content team. Staff sign in with email + code plus an authenticator-app code (two-step). For now the same teacher can write and publish.

IDScreenWhat it shows and does
S1Staff sign-inEmail + code, then authenticator-app code.
S2DashboardNew book uploads from families (with a notification badge), drafts in progress, recently published (last 7 days), open problem reports and open support tickets. Each count opens its queue.
S8Uploaded books queueEvery book or chapter a family uploads arrives here as a notification: family, child's class, subject, chapters, waiting time. Open one to start preparing it.
S9Prepare chapterChapter text side by side with Claude. The admin uses Claude to draft the animated lesson and a question bank (20+ questions with answers and the topic each one tests). Admin edits and previews, then sends it to the content check (S11). After the check passes, the admin publishes to that family only. The family gets "Lessons ready".
S11Content check reportA content-check agent reviews every lesson, question and answer before it can be published, and lists red flags by severity:
  • Not suitable for the child's age (violence, fear, adult topics, brand names, links).
  • Facts that don't match the chapter text, or wrong answers and solutions.
  • Spelling, grammar or Hindi script errors (e.g. broken conjunct letters).
  • Too hard or too easy for the class.
  • Bias or stereotypes (gender, caste, religion, region).
  • Any personal information.
Critical flags block publishing until fixed. Warnings can be accepted by the admin with a note. Each flag links to the exact part of the lesson.
S10Question bankAll questions by class, subject, chapter and topic, with answers and solutions. Worksheets and practice sets are built by shuffling from here.
S3LibraryClass → subject → topic tree of grade-level content (lessons, practice questions, worksheets, reading passages). Implemented in Plan 4.2: choose class and subject, then a topic; add a topic or a sub-topic, rename, archive or restore it; the topic's content is listed with type, status and version, and New lesson / New question / New reading passage open S5.
S4Draft with AIChoose class, subject, topic and content type. The AI drafts; the teacher edits. Implemented in Plan 4.3: lesson, question bank (5–30 questions) or reading passage, in English or Hindi. With AI drafts off (trial) the teacher copies our prompt into a Claude chat and pastes the reply. Each drafted item shows its problems or a preview; a lesson, passage or question opens in S5, and a question bank saves all ready questions as drafts at once. Nothing is saved before that.
S5Edit and previewEdit text, questions, answers, narration. Preview exactly as a child will see it. Implemented in Plan 4.2: lesson scenes (narration with picture and animation, or an inline published question), the four question types (multiple choice, true or false, fill in the blank, match) and reading passages, beside the kid-mode preview. Every save is a new version; the version list opens older versions read-only.
S6PublishAvailable only after the content check (S11) has no critical flags. Unpublish if something is wrong.
S12Support inbox"Contact us" tickets from parents, newest first, with status (open, answered, closed). Open a ticket to read the conversation and reply; the reply appears in the parent's messages.
S13StaffSuper admins only (added in Plan 4.1). Everyone with Studio access: name, role (content admin or super admin), active or switched off, date added. Add a staff member by email, name and role; they sign in with an emailed code and set up an authenticator app the first time. Change a name or role, or switch someone off. Nobody can change their own role or switch themselves off. The menu item is shown to super admins only.
S7Problem reportsReports from parents with the item, reason and note. Open the item, fix it, mark Fixed (sends the parent a message).

8User journeys

New parent signs up

  1. A1 → taps Sign up.
  2. A2 enters email, ticks consent → A3 enters the emailed code.
  3. B1 sets parent PIN → B2 adds child (Class 3).
  4. B3 uploads the English book, skips the rest → B4 picks 30 minutes.
  5. B5 → C1, hands the tablet over.

Returning parent on a new phone

  1. A1 → Sign in → A2 → A3.
  2. Lands on C1 with existing children.

Child's session

  1. C1 taps own picture → K1.
  2. Taps English → K2 → a chapter → K3 → watches a lesson (K4) → K7.
  3. Practice tab → Tables (K10) → 60-second challenge.
  4. Read tab → K13 → K14 gets stars.
  5. Time bar turns red; the child finishes and stops.

Parent adds a chapter

  1. Parent button → P0 PIN → Books (P4).
  2. Hindi → Add chapter (P7), takes 6 photos, saves.
  3. Status shows Getting ready; parent leaves.
  4. Bell message: "Hindi Ch 4 is ready to read along." Chapter appears for the child.
  5. Our admin gets a notification (S8) and prepares the lesson and questions (S9).
  6. Parent gets "Lessons for Hindi Ch 4 are ready. We recommend a quick preview." Watch lesson and worksheets unlock for the child.
  7. Parent opens the preview (P8a) and taps Looks good.

Parent prints and checks a worksheet

  1. Worksheets (P10) → Create (P11) → Maths, Chapter 3.
  2. P12 shares the PDF to print.
  3. After the child finishes, P13 opens solutions and ticks "carrying in addition" as a weak spot.
  4. It shows up in Areas to work on in Progress (P1).

Upload needs attention

  1. Bell message: "3 pages of your EVS book were unclear."
  2. P8 shows only those 3 pages → Retake photo for each.
  3. Status returns to Getting ready, then Ready.

New school year

  1. Settings → child (P15) → Move to next class.
  2. Warning that Class 3 progress will be erased → confirm.
  3. Subjects reset to Class 4; parent uploads new books.

Parent reports a problem

  1. In parent mode, opens a lesson → Report a problem (P18).
  2. Teacher sees it in S7, fixes it, marks Fixed.
  3. Parent gets "The lesson you reported has been fixed."

Admin prepares an uploaded book

  1. Notification: "New upload: Class 3 English, 12 chapters" → S8.
  2. Opens Chapter 1 in S9; Claude drafts the lesson and 25 questions.
  3. Admin edits and previews, then runs the content check (S11).
  4. Fixes the 1 critical flag (a wrong answer), accepts 1 warning with a note, publishes.
  5. Repeats per chapter; the family is told as each chapter is ready.

Teacher publishes content

  1. S1 sign in → S3 Class 3 → EVS → Water.
  2. S4 drafts a lesson and 10 questions with AI.
  3. S5 edits and previews → S11 content check → S6 publishes.

12Not in this version

  • Payments, free trial and subscriptions.
  • Hindi app language (English only; the Hindi subject stays).
  • Book list to pick from; more than one book per subject.
  • Computer subject.
  • Daily plan / Today tab, bonus activities, streaks, parent assigning lessons.
  • Child PIN.
  • Second parent login, sibling comparison.
  • SMS, WhatsApp or email messages.
  • Self-service account deletion (a deletion request is sent to the team instead).
  • Separate writer and approver roles in the Content Studio.

Lessons from uploaded chapters: each upload notifies our admin, who uses Claude in the Content Studio to prepare the lesson and question bank. Every item then passes three checks: the admin, a content-check agent that flags red flags (critical flags block publishing), and an optional but recommended parent preview. Children never see content that has not passed the first two. Worksheets are made by shuffling questions from the bank for the chapter or topic the parent picks.

13Changes made to the PRD

These decisions are now in PRD v1.2 and Tech Stack v1.2.

  • Kid mode: 3 tabs (Learn, Practice, Read); remove the Today tab and daily plan.
  • My books: no book list; one uploaded book per subject; grade-level content when no book.
  • Subjects: English, Hindi, Maths, EVS; Computer later.
  • Remove subscriptions, the trial conversion target and child PINs.
  • App language English only; worksheet marks entry replaced by solutions and weak-spot ticks.
  • Moving to the next class erases old progress.
  • Animated lessons for every grade-level topic and every uploaded chapter (the PRD currently lists lessons from uploaded books as "not in the first version"). Uploaded books notify our admin, who prepares lessons and a question bank with Claude and publishes them per family. Worksheets are shuffled from the question bank.
  • A content-check agent reviews all content before publishing; parents are advised (not required) to preview new lessons.
  • Upload limits: PDF up to 50 MB and 300 pages; photos up to 10 MB each, 50 per upload.
